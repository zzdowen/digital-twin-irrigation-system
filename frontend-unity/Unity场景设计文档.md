# Unity 3D 场景设计文档 v3.0.0（三路灌溉版）

> 本文档供建模/场景搭建人员按图施工。**3D 模型资产由建模人员绘制**，C# 脚本已由开发完成（见 `Assets/Scripts/`）。
> 数据接口遵循《系统接口契约v3.md》：3 路独立灌溉（花盆1/2/3）。

---

## 1. 场景总览

**主题**：一个现代化智能温室的局部 —— 3 个并排种植花盆，每个花盆配 1 台水泵 + 1 个土壤湿度传感器，共享一个储水箱。

**俯视布局示意**：

```
┌────────────────────────── 温室地面平台（约 10m × 6m）──────────────────────────┐
│                                                                                │
│   ┌──────────┐   ┌──────────┐   ┌──────────┐                                   │
│   │  花盆1    │   │  花盆2    │   │  花盆3    │      ← 三个花盆并排（中心线对齐） │
│   │ 🌱💧📟   │   │ 🌱💧📟   │   │ 🌱💧📟   │                                   │
│   └──────────┘   └──────────┘   └──────────┘                                   │
│        ↑              ↑              ↑                                         │
│   ┌──────────────────────────────────────────┐                                  │
│   │           水管主管道（从水箱引出）          │                                  │
│   └──────────────────────────────────────────┘                                  │
│                                                                                │
│   ┌────────┐  ┌────────┐  ┌────────┐  ┌──────────┐                             │
│   │ 水泵1   │  │ 水泵2   │  │ 水泵3   │  │ 储水箱    │   ← 设备区（花盆后方）      │
│   └────────┘  └────────┘  └────────┘  └──────────┘                             │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

**建议视角**：默认相机从斜上方 45° 俯视整个场景，三盆一屏可见。

## 2. 3D 模型清单（按绘制优先级排序）

### 2.1 花盆种植床（必需，核心）—— 3 个

| 属性 | 要求 |
|------|------|
| 尺寸 | 每个约 0.8m × 0.8m × 0.35m（长×宽×高） |
| 造型 | 方形种植箱，深色塑料/木纹材质 |
| 内部 | 土壤层（比盆沿低 5cm），土壤表面平整 |
| 命名规范 | `Planter_1`、`Planter_2`、`Planter_3` |
| 动态材质 | 土壤材质需**可切换颜色**（脚本控制）：>60% 深棕色湿润 / 30-60% 棕黄正常 / <30% 浅黄干燥 |

**土壤颜色驱动**：脚本 `IrrigationUIController` 会根据每路 `soil_moisture` 切换该花盆土壤材质颜色（需 3 个独立材质实例）。

### 2.2 土壤湿度传感器（必需）—— 3 个

| 属性 | 要求 |
|------|------|
| 造型 | 探针式：主体小块（约 5cm）+ 两根金属探针插入土中 |
| 位置 | 每个花盆土壤中插入一个，探针没入土中 2/3 |
| 命名规范 | `SoilSensor_1`、`SoilSensor_2`、`SoilSensor_3` |
| 指示灯 | 传感器主体上带一个**状态灯小球**（材质自发光，可切换绿/红/黄） |

### 2.3 水泵（必需）—— 3 台

| 属性 | 要求 |
|------|------|
| 造型 | 小型潜水泵/微型泵：方块+圆柱出水嘴，约 15cm |
| 位置 | 花盆后方的设备区，每个花盆对应一台 |
| 命名规范 | `Pump_1`、`Pump_2`、`Pump_3` |
| 指示灯 | 泵体上带 LED 指示（运行=蓝色亮，停止=灰色） |
| 动画 | **运行时有轻微震动动画**（可选加分） |

### 2.4 储水箱（必需）—— 1 个

| 属性 | 要求 |
|------|------|
| 造型 | 半透明蓝色塑料水箱，约 1m × 0.6m × 0.6m |
| 位置 | 设备区最右侧 |
| 命名规范 | `WaterTank` |

### 2.5 水管管道（必需）—— 1 套

| 属性 | 要求 |
|------|------|
| 造型 | 主管道从水箱引出，分 3 支到 3 个花盆上方（PVC 灰/白色圆柱） |
| 出口 | 每支末端在花盆上方，出水口对准土壤 |
| 命名规范 | `PipeMain`、`PipeBranch_1/2/3` |
| 水流效果 | 见 3.3（粒子效果由脚本控制开关） |

### 2.6 作物模型（必需）—— 3 组

| 属性 | 要求 |
|------|------|
| 造型 | 叶菜类（生菜/小白菜），每个花盆 3-5 株 |
| 命名规范 | `Crop_1_x`（x=1..5） |
| 生长阶段 | 至少 1 种形态即可（幼苗/成熟可选加分） |

### 2.7 温室结构（可选加分）

| 属性 | 要求 |
|------|------|
| 造型 | 透明玻璃墙 + 金属框架（如时间紧可只做地面平台 + 背景） |
| 尺寸 | 约 12m × 8m × 3m |

### 2.8 继电器控制箱（可选）

小型控制箱模型放设备区（`ControlBox`），可打开看到 4 路继电器（视觉加分）。

## 3. 动态效果清单（脚本驱动，模型需预留接口）

### 3.1 土壤湿度颜色（每盆独立）⭐核心

| 湿度范围 | 土壤颜色 | 说明 |
|----------|----------|------|
| > 60% | 深棕色 (#5D4037 附近) | 湿润 |
| 30-60% | 棕黄色 (#8D6E63 附近) | 正常 |
| < 30% | 浅黄偏白 (#D7CCC8 附近) | 干燥（配合 UI 告警） |

### 3.2 水泵状态指示（每台独立）⭐核心

| 状态 | 指示 |
|------|------|
| 运行中 | LED 蓝色亮 + 泵体轻微震动 |
| 停止 | LED 灰色 |

### 3.3 灌溉水流（每路独立）⭐核心

- 每支水管出口放一个 **Unity 粒子系统**（`WaterFlow_1/2/3`），默认关闭
- 脚本在对应泵启动时 `Play()`，停止时 `Stop()`
- 粒子：蓝色细长水滴，向下喷到花盆土壤

### 3.4 传感器状态灯（每盆独立，可选）

| 湿度状态 | 灯色 |
|----------|------|
| 正常（≥30%） | 绿色 |
| 干燥（<30%） | 红色闪烁 |

## 4. 场景层级结构（建议）

```
IrrigationScene/
├── Environment/                  # 地面平台 / 温室结构 / 背景
│   ├── GroundPlane
│   ├── Greenhouse（可选）
│   └── ...
├── Planters/                     # 3 个花盆
│   ├── Planter_1/  (含 Crop_1_*, SoilSensor_1, 土壤材质实例)
│   ├── Planter_2/
│   └── Planter_3/
├── Equipment/                    # 设备区
│   ├── WaterTank
│   ├── Pump_1 / Pump_2 / Pump_3  (含 LED 材质实例)
│   ├── ControlBox（可选）
│   └── Pipes/ (PipeMain + PipeBranch_1/2/3 + WaterFlow_1/2/3)
├── Scripts/                      # 挂脚本的空物体
│   ├── ApiClientObject           # 挂 IrrigationApiClient（可不挂，脚本懒加载）
│   ├── DataPollerObject          # 挂 RealtimeDataPoller
│   └── UIControllerObject        # 挂 IrrigationUIController
└── UI/
    └── Canvas                    # 见第 5 节
```


**UI 控件清单**（Unity UI 创建，脚本 `IrrigationUIController` 已预留绑定槽位）：

| 面板 | 控件 |
|------|------|
| 系统状态 | 4 个 Text（数据源/服务器状态/平均湿度/更新时间） |
| 三路数据 | 每路：1 个 Text（湿度数值）+ 1 个 Slider 或 Image(Filled)（湿度条）+ 1 个 Text（泵状态）+ 2 个 Button（启动/停止）+ 1 个 Text（灌溉时长） |
| 全局控制 | 3 个 Button（全部启动/全部停止/自动模式）+ 1 个 Slider（灌溉时长 1-30） |
| 连接状态 | 1 个 Text（连接中/在线/离线，三色） |

## 6. 给建模者的检查清单

- [ ] 3 个花盆（含土壤、作物、传感器探针），土壤材质**每盆独立实例**（颜色可分别改）
- [ ] 3 台水泵（带 LED 材质实例）+ 1 个水箱 + 水管（主管 + 3 分支）
- [ ] 3 个水流粒子系统（默认关闭，命名 `WaterFlow_1/2/3`）
- [ ] 模型命名符合第 2 节规范（脚本按命名/引用查找）
- [ ] UI Canvas 按第 5 节布局创建控件
- [ ] 所有模型材质尽量少而精，控制场景面数（性能要求 ≥30 FPS）

> 建模完成后，把模型拖进场景，按第 4 节层级组织，然后把脚本挂到 `Scripts/` 空物体上，
> 在 Inspector 里把各模型引用（土壤材质、LED、粒子、UI 控件）拖给 `IrrigationUIController` 对应槽位即可联调。
