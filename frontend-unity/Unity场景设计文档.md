# Unity 3D 场景设计文档 v4.0.0（三块农田版）

> 本文档供建模/场景搭建人员按图施工。**3D 模型资产由建模人员绘制**，C# 脚本已由开发完成（见 `Assets/Scripts/`）。
> 数据接口遵循《系统接口契约v3.md》：3 路独立灌溉（农田1/2/3）。
> 程序化场景（当前实现）由 `SceneBuilder` 一键生成，本文件同时作为手工建模时的施工规范。

---

## 1. 场景总览

**主题**：一个现代化智能温室中的 **3 块并排农田**，每块农田配 1 台水泵 + 1 支喷灌立管 + 1 个土壤湿度传感器，共享一个储水箱。作物成排种植在垄上，农田与农田之间留有田埂与步道。

**俯视布局示意**：

```
┌────────────────────────── 温室地面平台（约 17m × 13m）─────────────────────────┐
│                                                                                │
│   ┌──────────┐   ┌──────────┐   ┌──────────┐                                   │
│   │  农田1    │   │  农田2    │   │  农田3    │      ← 三块农田并排（中心线对齐） │
│   │ 🌱🌱🌱   │   │ 🌱🌱🌱   │   │ 🌱🌱🌱   │      每块约 3.4m × 2.6m          │
```

## 2. 3D 模型清单（按绘制优先级排序）

### 2.1 农田（必需，核心）—— 3 块

| 属性 | 要求 |
|------|------|
| 尺寸 | 每块约 3.4m × 2.6m（长×宽），田埂高约 0.16m |
| 造型 | 田埂四边围框（土色），内部土壤层低于田埂约 4cm，土壤表面有 3 条沿长边的种植垄（垄高约 5cm） |
| 命名规范 | `FarmField_1`、`FarmField_2`、`FarmField_3` |
| 动态材质 | 土壤材质需**可切换颜色**（脚本控制）：>60% 深棕色湿润 / 30-60% 棕黄正常 / <30% 浅黄干燥 |

**土壤颜色驱动**：脚本 `SceneDataBinder` 会根据每路 `soil_moisture` 切换该农田土壤材质颜色（需 3 个独立材质实例）。

### 2.2 土壤湿度传感器（必需）—— 3 个

| 属性 | 要求 |
|------|------|
| 造型 | 探针式：主体小块（约 5cm）+ 两根金属探针插入土中 |
| 位置 | 每块农田土壤前沿插入一个，探针没入土中 2/3 |
| 命名规范 | `SoilSensor_1`、`SoilSensor_2`、`SoilSensor_3` |
| 指示灯 | 传感器主体上带一个**状态灯小球**（材质自发光，可切换绿/红） |

### 2.3 水泵（必需）—— 3 台

| 属性 | 要求 |
|------|------|
| 造型 | 小型潜水泵/微型泵：方块+圆柱出水嘴，约 15cm |
| 位置 | 农田后方的设备区，每块农田对应一台 |
| 命名规范 | `Pump_1`、`Pump_2`、`Pump_3` |
| 指示灯 | 泵体上带 LED 指示（运行=蓝色亮，停止=灰色） |
| 动画 | **运行时有轻微震动动画**（可选加分） |

### 2.4 储水箱（必需）—— 1 个

| 属性 | 要求 |
|------|------|
| 造型 | 半透明蓝色塑料水箱，约 1m × 0.9m × 0.66m |
| 位置 | 设备区最右侧 |
| 命名规范 | `WaterTank` |

### 2.5 水管管道与喷灌立管（必需）—— 1 套

| 属性 | 要求 |
|------|------|
| 造型 | 主管道从水箱引出，分 3 支立管伸到每块农田中心上方（PVC 灰/白色圆柱），末端带喷头（横向十字管） |
| 出口 | 每支末端在农田中心正上方约 1.5m 处，向下喷灌覆盖整块农田 |
| 命名规范 | `PipeMain`、`PipeBranch_1/2/3` |
| 水流效果 | 见 3.3（粒子效果由脚本控制开关，Box 发射器覆盖整块农田） |

### 2.6 作物模型（必需）—— 3 组（每块农田 12 株，3 垄 × 4 株）

| 属性 | 要求 |
|------|------|
| 造型 | 叶菜类（生菜/小白菜），成排种植在种植垄上，株距约 0.75m、行距约 0.6m |
| 命名规范 | `Crop_x_y`（x=农田编号，y=1..12） |
| 生长阶段 | 至少 1 种形态即可（幼苗/成熟可选加分） |

### 2.7 温室结构（可选加分）

| 属性 | 要求 |
|------|------|
| 造型 | 透明玻璃墙 + 金属框架（如时间紧可只做地面平台 + 背景） |
| 尺寸 | 约 18m × 14m × 3m |

### 2.8 继电器控制箱（可选）

小型控制箱模型放设备区（`ControlBox`），可打开看到 4 路继电器（视觉加分）。

## 3. 动态效果清单（脚本驱动，模型需预留接口）

### 3.1 土壤湿度颜色（每块农田独立）⭐核心

| 湿度范围 | 土壤颜色 | 说明 |
|----------|----------|------|
| > 60% | 深棕色 (#5D4037 附近) | 湿润 |
| 30-60% | 棕黄色 (#8D6E63 附近) | 正常 |
| < 30% | 浅黄偏白 (#D7CCC8 附近) | 干燥（配合 UI 告警） |

### 3.2 水泵状态指示（每台独立）⭐核心

| 状态 | 指示 |
|------|------|
| 运行中 | LED 蓝色亮 + 泵体轻微震动 |
| 停止 | LED 灰色 |

### 3.3 喷灌水流（每块农田独立）⭐核心

- 每支喷头下方放一个 **Unity 粒子系统**（`WaterFlow_1/2/3`），默认关闭
- 发射器为 Box 形状，覆盖整块农田（约 3m × 2.4m），粒子向下飘洒模拟喷灌
- 脚本在对应泵启动时 `Play()`，停止时 `Stop()`
- 粒子：蓝色水滴，向下洒到农田土壤

### 3.4 传感器状态灯（每块农田独立）

| 湿度状态 | 灯色 |
|----------|------|
| 正常（≥30%） | 绿色 |
| 干燥（<30%） | 红色 |

## 4. 场景层级结构（建议）

```
IrrigationScene/
├── Environment/                  # 地面平台 / 温室结构 / 背景
│   ├── GroundPlane
│   ├── Greenhouse（可选）
│   └── ...
├── Farmland/                     # 3 块农田
│   ├── FarmField_1/  (含 Crop_1_*, SoilSensor_1, 土壤材质实例, 田埂/垄)
│   ├── FarmField_2/
│   └── FarmField_3/
├── Equipment/                    # 设备区
│   ├── WaterTank
│   ├── Pump_1 / Pump_2 / Pump_3  (含 LED 材质实例)
│   ├── ControlBox（可选）
│   └── Pipes/ (PipeMain + PipeBranch_1/2/3 + WaterFlow_1/2/3)
├── Scripts/                      # 挂脚本的空物体
│   ├── ApiClientObject           # 挂 IrrigationApiClient（可不挂，脚本懒加载）
│   ├── DataPollerObject          # 挂 RealtimeDataPoller
│   └── UIControllerObject        # 挂 DataPanelUI（程序化面板）
└── UI/
    └── Canvas                    # 见第 5 节
```

## 5. UI 布局设计（Canvas，玻璃风·紧凑版）

```
┌──────────────────────────── 屏幕（1920×1080）────────────────────────┐
│ 顶部细状态条（玻璃半透明）：数据源/在线状态 | 平均湿度 | 天气 | [收起▲]   │
├────────────────────────────────┬────────────────────────────────────┤
│ 左上：3 张农田卡片（300×96）     │ 右上：预测图表面板（636×368）          │
│  ●农田1  💧灌溉中              │  湿度预测·未来60分钟                 │
│  [████████░░] 49.1%           │  ●农田1 ●农田2 ●农田3（三线图）      │
│  [灌溉][停止]                 │  💧 灌溉统计（次数/用水/节水率）      │
│  ●农田2  ⏸待机               │  🌤 天气详情                         │
│  ...（农田3 同）               │                                    │
│                                │                                    │
│  ← 屏幕中央大部分区域留给 3D 农田场景 →                                │
├────────────────────────────────┴────────────────────────────────────┤
│ 底部细控制栏（玻璃半透明）：操作提示 | [全部灌溉] [全部停止] [自动模式]    │
└─────────────────────────────────────────────────────────────────────┘
```

**UI 设计要点**：

| 要点 | 说明 |
|------|------|
| 玻璃风 | 全部面板为运行时生成的圆角玻璃材质：半透明（α≈0.5）+ 淡蓝描边，3D 场景透出 |
| 占用小 | 仅顶部 44px 状态条、左上 3 张卡片、右上图表面板、底部 52px 控制栏，中央约 50% 屏幕留给场景 |
| 收起按钮 | 顶栏右侧「收起 ▲」一键隐藏/展开卡片、图表与底栏（淡入淡出 0.22s） |
| 控件清单 | 顶栏 3 Text + 1 Button；每卡片 3 Text + 1 进度条 + 2 Button；图表面板 4 Text + 折线图；底栏 1 Text + 3 Button |

> 程序化 UI 由 `DataPanelUI` + `UIGlass` 全代码生成，无需手工搭建；手工建模时也可按上图搭建并复用脚本。

## 6. 给建模者的检查清单

- [ ] 3 块农田（含田埂、种植垄、成排作物、传感器探针），土壤材质**每块独立实例**（颜色可分别改）
- [ ] 3 台水泵（带 LED 材质实例）+ 1 个水箱 + 水管（主管 + 3 支喷灌立管 + 喷头）
- [ ] 3 个喷灌粒子系统（默认关闭，Box 覆盖整块农田，命名 `WaterFlow_1/2/3`）
- [ ] 模型命名符合第 2 节规范（脚本按命名/引用查找）
- [ ] UI Canvas 按第 5 节布局创建控件（或直接使用程序化面板）
- [ ] 所有模型材质尽量少而精，控制场景面数（性能要求 ≥30 FPS）

> 建模完成后，把模型拖进场景，按第 4 节层级组织，然后把脚本挂到 `Scripts/` 空物体上，
> 在 Inspector 里把各模型引用（土壤材质、LED、粒子、UI 控件）拖给 `SceneDataBinder` / `DataPanelUI` 对应槽位即可联调。
