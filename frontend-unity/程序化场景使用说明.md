# 程序化场景使用说明（v3.0.0 动漫风格一键场景）

> 本套代码可**纯代码生成完整场景**：无需任何 3D 模型资产与 UI 手工搭建。
> 画面采用**动漫低模风格**（卡通阶梯光照 + 描边），性能友好（纯几何体组合，无贴图依赖，无碰撞体）。

---

## 一、功能总览

| 系统 | 说明 |
|------|------|
| 程序化建模 | 地面、3 花盆（土壤可变色）、作物、水泵×3、水箱、管道、传感器×3、太阳、云、飞鸟、雨 |
| 天气联动 | 定时拉取 `/api/weather`（OpenClaw AI 查询），驱动天空色/光照/云量/雨效/飞鸟 |
| 数据联动 | 湿度 → 土壤颜色；泵状态 → LED + 灌溉水流粒子；干燥 → 传感器红灯 |
| 数据面板 | 代码创建 Canvas：3 路湿度卡片（进度条+启停按钮）、3 路预测曲线、天气详情、全局控制 |
| 交互 | 左键旋转 / 右键平移 / 滚轮缩放；按钮控制灌溉（单盆/全部/自动模式） |

## 三、快速开始（3 步）

1. **配置服务器地址**：打开 `ApiConfig.cs`，把 `ServerUrl` 改为后端地址（本地调试默认 `http://localhost:5000`，真实地址见内部部署文档）。
2. **生成场景**（二选一）：
   - 运行模式：空场景挂 `SceneBuilder`，勾选 `Build On Start`，点 Play；
   - 编辑器模式：菜单栏 **「数字孪生灌溉 → 一键生成完整场景」**。
3. **观察效果**：左键拖拽旋转视角，滚轮缩放；数据面板自动出现，等待 2-5 秒数据接入。

## 四、各系统细节

### 1. 天气联动（WeatherController）
- 每 60 秒拉取一次 `/api/weather`；
- 晴天 → 蓝天 + 强太阳 + 少云；阴天 → 灰天 + 多云；降雨概率 >50% → 暗天 + 雨丝 + 飞鸟归巢；
- 天气不可用时自动保持晴天默认，不报错。

### 2. 数据联动（SceneDataBinder）
- 土壤：>60% 深棕 / 30-60% 棕黄 / <30% 浅黄（每盆独立）；
- 水泵：运行 = 蓝 LED + 水流粒子；停止 = 灰 LED；
- 传感器：<30% 红闪（干燥告警）。

### 3. 数据面板（DataPanelUI）
- 左上：数据源（模拟/真实设备）+ 平均湿度 + 天气摘要；
- 左侧：3 张湿度卡片（数值/进度条/泵状态/启动/停止）；
- 右侧：未来 60 分钟 3 路预测曲线（每 30 秒刷新）+ 天气详情；
- 底部：全部启动 / 全部停止 / 自动模式 + 操作提示。
- 中文字体运行时从系统加载（微软雅黑），无需字体资源。

### 4. 动漫渲染（ToonLit）
- 阶梯光照（3 档）+ 阴影色调 + 描边（inverted hull）；
- 全部材质统一走 `ProceduralStyle.CreateMaterial`，调色板集中在 `ProceduralStyle` 顶部。

## 五、自定义调参

| 位置 | 可调内容 |
|------|----------|
| `ProceduralStyle` 顶部 | 全部颜色（草地/土壤/天空/设备…） |
| `SceneBuilder` Inspector | 三路花盆 x 坐标、是否建 UI |
| `ProceduralFarmland` | 花盆尺寸 |
| `WeatherController` | 天气刷新间隔 |
| `DataPanelUI` | 默认灌溉时长、预测时长 |

## 六、性能说明

- 纯几何体组合（约 200 个 primitive），无贴图/无碰撞体/共享材质；
- 粒子总量受限（雨 ≤2500、水流每盆 ≤500）；
- 目标 ≥30 FPS（比赛要求），低配机可关闭 `SceneBuilder.buildUI` 中的预测刷新频率或减少云/鸟数量。

## 七、与手工建模的关系

程序化模型是**可替换**的：若你之后按《Unity场景设计文档.md》绘制了精细 3D 模型，
只需把对应生成器换成预制体实例，`SceneDataBinder` / `WeatherController` / `DataPanelUI`
的数据联动逻辑完全复用，无需改动。
