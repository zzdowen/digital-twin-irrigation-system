# 数字孪生灌溉系统 — 系统接口契约 v3.0.0

> 本文档是 ESP32 固件 / Python 后端 / Unity 前端三方对齐的唯一基准。
> v3.0.0 起，系统升级为 **3 路独立灌溉**（3 个花盆），温湿度字段已移除。

---

## 1. 核心数据模型

3 个灌溉单元（花盆），编号 `1 / 2 / 3`。每个单元：

| 字段 | 类型 | 说明 |
|------|------|------|
| `soil_moisture` | float | 土壤湿度百分比 0~100 |
| `pump_status` | bool | 水泵是否运行 |
| `irrigation_duration` | int | 当前灌溉已持续秒数 |

> 温湿度（temperature / humidity）自 v3.0.0 起**彻底移除**（实物无温湿度传感器）。

---

## 2. MQTT 主题（ESP32 ↔ 服务器）

基础主题：`farm/device01`

### 2.1 数据上报（ESP32 → 服务器）

- 主题：`farm/device01/sensors`
- 频率：每 5 秒
- payload（JSON，一次上报 3 路）：

```json
{
  "soil_1": 45.2,
  "soil_2": 50.1,
  "soil_3": 38.7,
  "pump_1": false,
  "pump_2": true,
  "pump_3": false
}
```

### 2.2 心跳（ESP32 → 服务器，可选）

- 主题：`farm/device01/status`
- payload：`{"online": true, "rssi": -60}`

### 2.3 控制指令（服务器 → ESP32）

- 主题：`farm/device01/control`
- payload：

```json
{"channel": 2, "action": "start", "duration_minutes": 5}
```

| 字段 | 取值 | 说明 |
|------|------|------|
| `channel` | 1 / 2 / 3 / `"all"` | 目标花盆，`all` 表示全部 |
| `action` | `start` / `stop` | 启动或停止灌溉 |
| `duration_minutes` | int（可选） | 仅 start 有效，灌溉时长（分钟） |

## 3. HTTP API（服务器 → Unity）

基础地址：`http://localhost:5000`（部署后替换，真实 IP 见内部部署文档）

### 3.1 `GET /api/realtime-data`

```json
{
  "channels": [
    {"channel": 1, "soil_moisture": 45.2, "pump_status": false, "irrigation_duration": 0},
    {"channel": 2, "soil_moisture": 50.1, "pump_status": true,  "irrigation_duration": 120},
    {"channel": 3, "soil_moisture": 38.7, "pump_status": false, "irrigation_duration": 0}
  ],
  "soil_moisture_avg": 44.7,
  "active_pumps": 1,
  "data_source": "simulated",
  "auto_irrigation_enabled": true,
  "last_update": "2026-08-13T23:00:00"
}
```

### 3.2 `POST /api/control-pump`

请求：
```json
{"channel": 2, "action": "start", "duration_minutes": 5}
```
（`channel` 可选，默认 1；`action` 可选值 `start` / `stop` / `auto`）

响应：
```json
{"status": "success", "message": "花盆2 灌溉已启动", "channel": 2, "pump_status": true}
```

### 3.3 `GET /api/historical-data?hours=24`

```json
{
  "channels": [
    [{"timestamp": "...", "soil_moisture": 45.2, "pump_status": false}],
    [...],
    [...]
  ],
  "total_points": 288,
  "query_range_hours": 24
}
```
> `channels` 为数组，下标 0/1/2 分别对应花盆 1/2/3（Unity JsonUtility 兼容）。

### 3.4 `GET /api/prediction?minutes=30`

```json
{
  "predictions": [
    [{"future_time": "...", "minutes_ahead": 5, "predicted_soil_moisture": 44.0, "confidence": 0.95}],
    [...],
    [...]
  ],
  "current_conditions": { /* 同 realtime-data */ },
  "prediction_horizon_minutes": 30,
  "algorithm_info": "基于历史趋势的土壤湿度预测模型"
}
```
> `predictions` 为数组，下标 0/1/2 分别对应花盆 1/2/3（Unity JsonUtility 兼容）。

### 3.5 `GET /api/system-status`

```json
{
  "system_running": true,
  "uptime_seconds": 12345,
  "data_points_collected": 288,
  "server_time": "...",
  "api_version": "3.0.0",
  "data_source_mode": "auto",
  "data_source": "simulated",
  "weather": {"enabled": true, "city": "大连", "forecast": [...], "updated_at": "..."}
}
```

### 3.6 `GET /api/weather`（天气感知，可选）

```json
{
  "enabled": true,
  "city": "大连",
  "forecast": [
    {"date": "2026-08-14", "weather": "阵雨", "temperature_c": 26.6, "rain_probability_percent": 82}
  ],
  "updated_at": "...",
  "last_error": null
}
```
> 由 OpenClaw AI 联网查询（每 30 分钟刷新）。`enabled=false` 或 `forecast=null` 表示不可用，前端隐藏天气显示即可。
> 预测接口的 `weather_forecast` 字段与 `algorithm_info` 会随天气可用性变化。

## 4. 数据源模式（后端环境变量 DATA_SOURCE）

| 模式 | 行为 |
|------|------|
| `auto`（默认） | MQTT 收到真实数据就用真实值；超时 30 秒自动回退模拟 |
| `simulated` | 始终内置模拟（3 路） |
| `mqtt` | 始终真实传感器数据 |
