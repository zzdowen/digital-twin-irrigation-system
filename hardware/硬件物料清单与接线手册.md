# 智慧农业灌溉系统 物料清单与接线手册

> 本文档记录实物硬件的最终物料清单与接线方式，是 ESP32 固件开发与联调的硬件依据。

---

## 一、最终硬件物料清单

| 类别 | 名称 | 数量 | 备注说明 |
| :--- | :--- | :--- | :--- |
| 核心主控 | ESP32-WROOM-32 开发板（Type-C款） | 1块 | 自带WiFi，负责数据采集、MQTT通信、水泵逻辑控制 |
| 驱动模块 | 5V 4路光耦隔离继电器模块 | 1块 | 低电平触发，用于隔离控制3路水泵，剩余1路预留备用 |
| 传感器 | 电容式土壤湿度传感器（v1.2/v2.0） | 3个 | 对应3个花盆/模拟农田，优先选电容式，长期使用不易腐蚀 |
| 执行器件 | 5V 微型潜水泵 | 3台 | 单盆独立控制，工作电压5V，适配整套系统供电 |

| 辅材 | 杜邦线（公对公、公对母、母对母） | 若干 | 用于模块间接线，建议各备20根 |

| 辅材 | 硅胶水管、三通接头、储水容器 | 若干 | 输水配套耗材，根据花盆实际距离选购 |

## 二、详细接线说明

### 2.1 模块引脚分区说明

4路光耦继电器模块分为两侧，接线前先确认方向：

- **低压控制侧（信号侧）**：共6个引脚，依次为 `VCC`、`GND`、`IN1`、`IN2`、`IN3`、`IN4`，接ESP32，为弱电信号
- **负载输出侧（功率侧）**：共4组端子，每组3个，依次为 `NC`（常闭）、`COM`（公共端）、`NO`（常开），接水泵与主电源
- 本方案全部使用**常开模式**，`NC` 端子全程空置不接

### 2.2 ESP32 ↔ 4路继电器（低压控制侧）

实现ESP32输出信号控制继电器通断，全部为弱电接线。

| 4路继电器引脚 | ESP32 开发板引脚 | 对应功能 | 关键备注 |
| :--- | :--- | :--- | :--- |
| VCC | 5V（或VIN引脚） | 继电器模块供电 | **必须接5V**，接3.3V会导致继电器无法正常吸合 |
| GND | GND | 信号共地 | 必须连接，是所有模块稳定工作的基础 |
| IN1 | GPIO25 | 控制第1路水泵（花盆1） | 低电平触发：输出LOW=水泵开，输出HIGH=水泵关 |
| IN2 | GPIO26 | 控制第2路水泵（花盆2） | 同上 |
| IN3 | GPIO27 | 控制第3路水泵（花盆3） | 同上 |
| IN4 | 空置不接 | 第4路预留备用 | 后续扩展设备可再使用 |

### 2.3 ESP32 ↔ 3路土壤湿度传感器

电容式土壤湿度传感器共3个有效引脚：`VCC`、`GND`、`AO`（模拟量输出），`DO` 数字阈值引脚空置不用。

| 土壤湿度传感器引脚 | ESP32 开发板引脚 | 对应对象 | 关键备注 |
| :--- | :--- | :--- | :--- |
| 传感器1 VCC | 3.3V | 花盆1 | 3个传感器的VCC可并联后统一接3.3V |
| 传感器2 VCC | 3.3V | 花盆2 | **严禁接5V**，否则会烧坏ESP32的ADC采集引脚 |
| 传感器3 VCC | 3.3V | 花盆3 |  |
| 传感器1 GND | GND | 花盆1 | 3个传感器的GND可并联后统一接GND |
| 传感器2 GND | GND | 花盆2 |  |
| 传感器3 GND | GND | 花盆3 |  |
| 传感器1 AO | GPIO34 | 花盆1湿度采集 | ADC1通道，连接WiFi时可正常使用，无冲突 |
| 传感器2 AO | GPIO35 | 花盆2湿度采集 | ADC1通道 |
| 传感器3 AO | GPIO32 | 花盆3湿度采集 | ADC1通道 |

### 2.4 继电器负载侧 ↔ 水泵 + 主电源

继电器负责通断水泵的供电回路，每一路独立控制一台水泵，互不干扰。

| 继电器负载侧端子 | 接线对象 | 对应水泵 | 说明 |
| :--- | :--- | :--- | :--- |
| 第1路 COM | 主电源 5V 正极 | 花盆1水泵 | 公共端，继电器吸合后与NO接通 |
| 第1路 NO | 水泵1 正极 | 花盆1水泵 | 常开端子，默认断开 |
| 第2路 COM | 主电源 5V 正极 | 花盆2水泵 | 可将3路COM端子用短线并联，再接主电源正极 |
| 第2路 NO | 水泵2 正极 | 花盆2水泵 |  |
| 第3路 COM | 主电源 5V 正极 | 花盆3水泵 |  |
| 第3路 NO | 水泵3 正极 | 花盆3水泵 |  |
| 所有水泵 负极 | 主电源 5V 负极 | 全部水泵 | 统一并联后接电源负极 |
| 第4路 全部端子 | 空置不接 | 备用 |  |
| 所有 NC 端子 | 空置不接 | - | 常闭端子，本方案不使用 |

### 2.5 全局电源汇总与共地要求

所有模块必须**共地**（负极全部连通），否则会出现传感器读数跳变、继电器误触发等异常。

#### 主电源 5V 正极（并联分流）
1. 接入继电器低压侧的 `VCC` 引脚（给继电器控制板供电）
2. 接入继电器负载侧并联后的 `COM` 端子（给水泵供电）
3. 接入ESP32的 `5V/Vin` 引脚（给ESP32主控供电）

#### 主电源 5V 负极（GND，全部并联）
1. 连接继电器低压侧的 `GND` 引脚
2. 连接ESP32的 `GND` 引脚
3. 连接3个土壤湿度传感器的 `GND` 引脚
4. 连接3台水泵的负极

## 三、通电自检步骤（必做，避免烧件）

1. **断电接线**：全程先不插电源，所有接线完成后再通电
2. **空载测试**：先不接水泵，仅连接ESP32、继电器、传感器，接通电源
3. **基础检查**：ESP32板载电源灯常亮，继电器4个状态灯全部熄灭，为正常状态
4. **功能验证**：上传测试代码，依次让GPIO25/26/27输出低电平，对应继电器会发出"咔哒"吸合声，同时对应状态灯点亮，说明控制回路接线正常
5. **带载测试**：确认3路继电器均正常后，断电接入水泵，再通电完成最终测试

---

## 四、关键注意事项

1. **电源正负极严禁反接**，反接会直接烧毁ESP32与继电器模块
2. 土壤湿度传感器供电为 **3.3V**，继电器模块供电为 **5V**，二者不可混淆
3. 水泵不可直接连接ESP32的IO引脚，必须经过继电器驱动
4. 所有模块的GND必须连通，共地是弱电系统稳定工作的核心前提
5. 水泵启动瞬间电流较大，请勿使用功率不足的电源，避免ESP32意外重启

## 五、引脚速查表（固件开发用）

| 功能 | ESP32 引脚 | 电平/说明 |
| :--- | :--- | :--- |
| 水泵1 控制 | GPIO25 | 低电平触发（LOW=开泵，HIGH=关泵） |
| 水泵2 控制 | GPIO26 | 同上 |
| 水泵3 控制 | GPIO27 | 同上 |
| 土壤湿度1 采集 | GPIO34 | ADC1（0~3.3V 模拟量） |
| 土壤湿度2 采集 | GPIO35 | ADC1 |
| 土壤湿度3 采集 | GPIO32 | ADC1 |

> 注意：GPIO34/35/32 为 ADC1 输入专用引脚，无内部上拉，仅作模拟输入；连接 WiFi 时仍可正常采集（无冲突）。
