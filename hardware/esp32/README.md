# 🤖 硬件模块 - ESP32

## 概述
ESP32 负责传感器数据采集和设备控制，通过 MQTT 协议与云服务器通信。

## 硬件清单
| 组件 | 型号 | 用途 |
|------|------|------|
| 开发板 | ESP32 DevKit | 主控 |
| 土壤湿度传感器 | 电容式/电阻式 | 土壤湿度测量 |
| 温湿度传感器 | DHT11/DHT22 | 环境温湿度 |
| 继电器模块 | 5V 单路 | 水泵控制 |
| 水泵/电磁阀 | 5-12V | 灌溉执行机构 |

## 引脚分配
| 功能 | 引脚 |
|------|------|
| DHT 数据 | GPIO4 |
| 土壤传感器 (ADC) | GPIO34 |
| 继电器控制 | GPIO25 |

## MQTT 主题
| 主题 | 方向 | 说明 |
|------|------|------|
| `farm/device01/sensor` | 上报 | 传感器数据 |
| `farm/device01/control` | 下发 | 控制指令 |

## 快速开始
1. 安装 Arduino IDE + ESP32 开发板支持
2. 安装依赖库: PubSubClient, DHT sensor library
3. 修改 `esp32_irrigation.ino` 中的 WiFi 配置
4. 烧录并查看串口输出
