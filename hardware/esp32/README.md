# 🤖 硬件模块 - ESP32（v3.0.0 三路灌溉）

## 概述

ESP32 作为边缘主控，负责 3 路土壤湿度采集 + 3 路水泵继电器控制，通过 MQTT 与云服务器通信（每 5 秒上报，订阅控制指令）。完整接线见 `../硬件物料清单与接线手册.md`。

## 硬件清单（最终）

| 组件 | 数量 | 用途 |
|------|------|------|
| ESP32-WROOM-32 开发板（Type-C） | 1 | 主控（WiFi + ADC + GPIO） |
| 电容式土壤湿度传感器（v1.2/v2.0） | 3 | 3 个花盆湿度采集（3.3V 供电） |
| 5V 4 路光耦继电器模块（低电平触发） | 1 | 驱动 3 路水泵（1 路预留） |
| 5V 微型潜水泵 | 3 | 灌溉执行机构 |
| 5V 3A 开关电源 | 1 | 统一供电 |

> 无温湿度传感器（DHT 已移除）。

## 引脚分配

| 功能 | GPIO | 说明 |
|------|------|------|
| 水泵1/2/3 | 25/26/27 | 低电平触发：LOW=开泵，HIGH=关泵 |
| 湿度1/2/3 | 34/35/32 | ADC1（0~3.3V 模拟量，与 WiFi 无冲突） |

## MQTT 主题（《系统接口契约v3.md》）

| 主题 | 方向 | 说明 |
|------|------|------|
| `farm/device01/sensors` | 上报（5秒） | `{"soil_1":..,"soil_2":..,"soil_3":..,"pump_1":..,"pump_2":..,"pump_3":..}` |
| `farm/device01/status` | 上报（30秒） | 心跳 `{"online":true,"rssi":-60}` |
| `farm/device01/control` | 订阅 | `{"channel":2,"action":"start","duration_minutes":5}` |

## 烧录步骤

1. Arduino IDE 安装 ESP32 开发板支持（`ESP32 Dev Module`）
2. 库管理器安装：`PubSubClient by Nick O'Leary`
3. 修改 `esp32_irrigation.ino` 顶部：WiFi 名称/密码、MQTT 服务器 IP（真实 IP 见内部部署文档，勿提交）
4. **标定土壤湿度**（重要）：烧录后看串口打印的 ADC 原始值——
   - 传感器悬空（最干）读数 → 填入 `DRY_ADC`
   - 传感器浸水（最湿）读数 → 填入 `WET_ADC`
   - 若传感器"越湿读数越小"（反相），交换两个值即可
5. 烧录并观察串口输出（每 5 秒一条上报日志）

## 通电自检（必做，见接线手册第三节）

断电接线 → 空载测试（不接水泵）→ 继电器"咔哒"声验证 → 带载测试。

## 固件功能

- [x] 3 路 ADC 采集（多次采样取平均 + 线性标定）
- [x] 3 路水泵控制（低电平触发 + 到时自动关泵）
- [x] MQTT 上报 + 订阅控制 + 断线自动重连
- [x] 本地自动灌溉兜底（湿度<30% 自动开泵 10 分钟）
